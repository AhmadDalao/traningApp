TRAINING PLANNER · RELEASE v2.6.0 · 10 NOVEMBER 2026

A clearer coaching workspace

The supplied violet and navy design, applied to the existing application and its real data.

NOT READY — production verification pending

What changed

  • Dark navy Coach sidebar, violet actions, lavender surfaces, consistent cards and tables, breadcrumb navigation and a grouped workspace menu.
  • Overview priority banner, bounded scrolling lists, larger workout thumbnails, seven-day workload chart and trainee momentum.
  • Trainee roster with name sorting, name/ID/current-program search, page-size controls and separate coaching status and attention indicators.
  • Programs default to a paginated list, with an optional grid, authored-workout readiness filters, thumbnails and existing assignment actions.
  • Subscriptions and Coaching packages use distinct tabs. Periods keep separate start/end dates, status, time remaining, filters and independent pause/resume/end/renew controls.
  • Settings uses a desktop section sidebar and mobile settings directory with focused pages and Back navigation. Coach profile bio is a multiline field with a character count.
  • Notifications and App & devices are separate Coach settings sections. Mobile Coach navigation provides Overview, Trainees, Programs, Subscriptions and Settings.

Existing behavior preserved

Baseline: immutable v2.5.2 application d779a5cdf74973255d863dc650654e7379257681, with later deployment documentation at 46f1869. The update uses the existing Laravel / React / Inertia architecture, authorization, independent program subscriptions, atomic activation and scheduling services. No schema migration or new dependency.

Personal Workspace retains its own theme. Workout logging, History, Progress/PR, Anytime semantics, consent and Coach ownership remain unchanged. Thumbnails still open full images. New statistics and filters are read-only and use Coach-authorized queries.

Workload counts scheduled training in the current application-local week; completed workouts form a subset of each bar. Momentum shows completed / all scheduled workouts for the week, not due-only adherence. The roster’s “On track” filter reflects operational state; subscription status is shown separately.

“Workouts ready” means at least one training day has exercises and no authored training day is empty. Existing activation still validates program definition, dates and coverage. This is not a new readiness or lifecycle engine.

Data integrity and limits

Local QA used 16 disposable accounts. All were removed, along with 15 QA image copies. All 22 original domain table fingerprints and 44 original media hashes matched after cleanup.

Push remains disabled under the approved configuration. No VAPID credentials or scheduler changes are introduced. The design does not add unsupported trainee-activity digests, product-news toggles, avatar uploads, offline workout access or a device inventory. Existing current-device enable/disable and installation guidance remain available.

Overview attention and momentum lists show up to 100 trainees, with the full paginated roster available. Programs retain 10/25/50/100 page sizes; the default is list view. No BLOCKER or HIGH issue is known after the completed local gates.
