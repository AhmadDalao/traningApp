TRAINING PLANNER · RELEASE REPORT · 9 NOVEMBER 2026

v2.5.2 — Subscription directory

A clearer view of who is subscribed, their assigned training, and when coaching starts and ends.

NOT READY — production verification pending

What changed

  • Separate start-date and end-date columns, both showing the year.
  • One row per subscription period with trainee name/Training Planner ID, program thumbnail, coaching package, status and actions.
  • Time remaining: ends today/tomorrow, days until end, upcoming start countdown, expired period age, or ongoing coverage with no end date.
  • Live search by trainee name, ID, program or package; trainee and status filters; active subscriptions ending within 7 or 30 days; ongoing coverage.
  • Sort by newest, earliest end date, or earliest start date. Open-ended periods appear last when sorting by end date.
  • Default 10 items per page; choices 10/25/50/100 and a clear showing X–Y of N result range.
  • The same date/status table is reused inside a trainee’s coaching page. Mobile layouts use readable cards with paired dates.

Preserved behavior

Existing independent program subscriptions, pause/resume/end/renew controls, program ownership, history and private notes remain intact. Dates use the application’s Asia/Riyadh calendar day. The ending-soon filters include active periods only; the ongoing filter includes active/paused open-ended periods. Status totals cover all the Coach’s subscriptions; the result range reflects the chosen filters.

No payment, account-approval or gender fields were invented from the reference screenshot. This update does not add billing, change coverage, or modify the database schema.
